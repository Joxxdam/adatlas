# 영상 레퍼런스 블루프린트

영상 기획의 기본 흐름은 기존 `ProductTruth → 후킹 → 콘셉트 → 상세 장면`을 유지합니다. 분석이 끝난 11개 영상은 새 제작 엔진이 아니라, 콘셉트와 장면 구성을 안정시키는 큐레이션 블루프린트로 사용합니다.

## 적용 방식

1. 상품명·카테고리·USP로 뷰티, 육류, 과일·농산물, 일반 식품을 판별합니다.
2. 패러디, 리얼 후기, USP 집중, 시크릿 혜택의 네 콘셉트마다 주 레퍼런스를 하나씩 배정합니다.
3. 주 레퍼런스에서는 5단계 전체 전개와 편집 리듬을 가져옵니다.
4. 보조 레퍼런스에서는 훅 또는 CTA 장치 하나만 참고합니다.
5. 상세 장면을 만들 때 각 장면에 화면·구도, 연출, 전환, 필요 소스를 함께 기록합니다.

## 안전 규칙

- 레퍼런스의 원문 자막, 인물, 상품 사실은 복제하지 않습니다.
- 가격·할인·배송·증정·효능은 현재 상품의 ProductTruth에서 확인된 정보만 씁니다.
- 식품 안에서는 육류와 과일·농산물 레퍼런스의 문안 구조와 콘텐츠 전개를 서로 참고할 수 있습니다.
- 상품과 직접 맞는 카테고리의 사용·질감 장면을 우선하되, 다른 카테고리는 훅·증거·CTA 구조만 전용합니다.
- 사용자가 별도로 업로드해 분석한 영상 레퍼런스는 큐레이션 블루프린트와 함께 보조 신호로 유지합니다.

## 데이터 위치

- 블루프린트: `app/lib/video-collaboration/videoPlanningBlueprints.ts`
- 영상 기획 생성: `app/lib/video-collaboration/videoPlanningGenerator.server.ts`
- 프로젝트/콘셉트 화면: `app/components/video-planning/`

블루프린트를 추가할 때는 고유 ID, 상품군, 적용 가능한 콘셉트 유형, 원본 길이·장면 수, 5단계 비트, 전용 가능한 원칙을 함께 등록합니다.
