# 애드아틀란티스(AdAtlas) MVP 최종 기획서

> 역사적 후킹 실험·성과 연결 기획서입니다. 현재 광고 6장 생성 방식은 [ZIP 레퍼런스 생성 명세](creative-generation-spec.md)와 [운영 Runbook](creative-generation-runbook.md)을 따릅니다. 이 문서의 `동일 디자인 후킹 실험`은 성과 실험 설계이며 `/create-product`의 기본 이미지 생성 방식이 아닙니다.

> 문서 버전: 2.0  
> 최종 수정일: 2026-08-13  
> MVP 테스트 원칙: 동일 디자인에서 후킹 메시지만 변경한다.

## 1. 핵심 소개

애드아틀란티스는 **동일한 광고 디자인에 서로 다른 후킹을 적용해 실제 광고 성과를 비교하고, 고객이 반응하는 메시지를 학습하는 AI 광고 콘텐츠 실험 시스템**이다.

광고할 상품을 발견하고, 상품 사실과 고객 맥락을 분석해 서로 다른 후킹 가설을 만들며, 동일한 디자인 조건의 광고 소재로 실제 성과를 비교한다. 생성된 소재에는 고유코드를 부여하여 이미지 파일명·광고명·UTM·내부 기록·성과 보고서를 하나로 연결한다.

이번 MVP는 후킹과 디자인을 동시에 최적화하는 시스템이 아니다. 배경·레이아웃·상품 크기·색상·CTA 등 비주얼 요소는 실험 중 고정하며, **고객 반응을 만드는 메시지가 무엇인지 확인하는 데 집중한다.**

---

## 2. 해결하려는 문제

이커머스 광고 운영에서는 다음 문제가 반복된다.

- 어떤 상품을 지금 광고해야 하는지 판단하기 어렵다.
- 광고 소재를 많이 만들어도 어떤 메시지가 성과를 만들었는지 남지 않는다.
- 문구와 디자인이 동시에 달라져 성과 차이의 원인을 해석하기 어렵다.
- 이미지 파일, 광고명, UTM, 성과 보고서가 서로 연결되지 않는다.
- 한 번 성과가 좋았던 후킹이 다음 콘텐츠 제작에 체계적으로 재사용되지 않는다.
- 크리마켓 데이터가 없는 광고주는 데이터 기반 제작 흐름에서 제외되기 쉽다.

애드아틀란티스는 이를 다음 구조로 해결한다.

```text
광고 기회 상품 탐지 또는 상세페이지 분석
→ 상품 사실·USP·후기 인사이트 정리
→ 후킹 가설 8개 생성
→ 하나의 광고 디자인 확정
→ 후킹 메시지가 다른 광고 이미지 6장 제작
→ 소재코드 발급 및 광고 등록
→ 실제 광고 성과 연결
→ 목표별 후킹 성과 비교
→ 우승 후킹을 다음 콘텐츠 제작에 전달
```

## 3. MVP의 핵심 목적

이번 MVP의 목적은 다음 한 문장으로 정의한다.

> 동일한 광고 디자인에 서로 다른 후킹을 적용해 실제 광고 성과를 비교하고, 고객이 반응하는 메시지를 학습한다.

MVP에서 확인할 질문은 아래와 같다.

1. 같은 상품과 같은 디자인에서 어떤 메시지 가설이 가장 높은 고객 반응을 만드는가?
2. 신규 후킹은 기존 우승 소재보다 실제로 개선되었는가?
3. 캠페인 목표에 맞는 핵심 성과를 만든 후킹은 무엇인가?
4. 다음 콘텐츠에서도 유지해야 할 메시지 방향은 무엇인가?

MVP에서 답하지 않는 질문은 아래와 같다.

- 어떤 배경이 더 효과적인가?
- 어떤 레이아웃이나 상품 배치가 더 효과적인가?
- 제품을 크게 보여주는 것이 더 좋은가?
- 가격을 먼저 보여주는 것과 효능을 먼저 보여주는 것 중 무엇이 좋은가?
- 긴 카피와 짧은 카피 중 무엇이 좋은가?
- 후킹 효과와 비주얼 효과가 각각 몇 퍼센트의 성과를 만들었는가?

이 질문들은 데이터와 운영량이 충분해진 이후의 고도화 범위로 이동한다.

## 4. 제품 범위와 두 가지 진입 방식

애드아틀란티스는 크리마켓 연결 여부와 관계없이 사용할 수 있어야 한다.

### 4.1 크리마켓 연결 광고주

```text
크리마켓 데이터 연결
→ 상품·카테고리 성과 분석
→ 광고 기회 상품 자동 탐지
→ 추천 근거 확인
→ 상품 선택
→ 상세페이지·후기 인사이트 보완
→ 후킹 실험 시작
```

크리마켓 데이터는 광고할 상품을 먼저 찾아주는 고급 기능이다. 상품별 판매·조회·주문·리뷰·재고 등 실제로 수집된 값만 사용하며, 미수집 값을 0으로 바꾸거나 AI가 추정하지 않는다.

### 4.2 크리마켓 미연결 광고주

```text
상품 상세페이지 URL 입력
→ 상품명·가격·혜택·USP·이미지 분석
→ 후기·브랜드·카테고리 신호 정리
→ 후킹 실험 시작
```

크리마켓 미연결은 오류가 아니다. 상세페이지 분석을 기본 진입 방식으로 제공하며, 소재코드·광고 등록·성과 연결·후킹 학습 기능은 동일하게 지원한다.

### 4.3 유지하는 기존 일반 제작 기능

기존의 상품 선택 제작, 상세페이지 분석, 문구 생성, 이미지 선택, 배경·템플릿 선택, 단일 또는 일괄 렌더링, 다운로드 기능은 삭제하지 않는다.

다만 일반 콘텐츠 제작과 후킹 실험은 목적을 구분한다.

| 구분             | 일반 콘텐츠 제작                | MVP 후킹 실험                 |
| ---------------- | ------------------------------- | ----------------------------- |
| 목적             | 다양한 광고 콘텐츠 제작         | 후킹 메시지 성과 비교         |
| 디자인           | 콘텐츠별로 달라질 수 있음       | 모든 T01 소재에서 고정        |
| 메시지           | 제작 목적에 따라 달라질 수 있음 | 후킹 가설별로 변경            |
| 결과 해석        | 제작 결과물                     | 실제 집행 성과 기반 후킹 순위 |
| 비주얼 성과 학습 | 하지 않음                       | 하지 않음                     |

## 5. 광고 기회 상품 탐지

크리마켓 연결 광고주에게는 단순 매출 순위가 아니라 광고 행동으로 이어질 후보를 제안한다.

### 5.1 탐지 후보

- 최근 반응이 빠르게 성장한 상품
- 노출은 적지만 구매 가능성이 확인되는 상품
- 조회는 많지만 구매 전환이 낮아 메시지 검증이 필요한 상품
- 리뷰 반응과 반복 언급이 좋아 광고 메시지로 확장할 수 있는 상품
- 과거 성과는 있었지만 최근 광고 노출이 줄어든 상품
- 신상품 또는 아직 충분히 테스트하지 않은 상품
- 재고·환불·품절·상세페이지 품질 문제로 광고보다 개선이 먼저 필요한 상품

### 5.2 추천 결과

상품별로 다음을 표시한다.

- 추천 또는 제외 유형
- 사용한 실제 데이터 기간
- 추천 근거
- 확인된 위험 요소
- 후킹으로 확장할 수 있는 상품 사실
- 상세페이지 또는 혜택 수정이 먼저 필요한지 여부
- `이 상품으로 후킹 실험하기` 행동

판매량·매출·재고·마진·ROAS 등 공개되거나 연결되지 않은 수치는 생성하지 않는다.

## 6. 상품 및 상세페이지 분석

상품 선택 후 아래 정보를 `ProductTruth`로 정리한다.

- 상품명과 브랜드
- 카테고리와 세부 유형
- 현재 가격과 확인 가능한 기존 가격
- 실제 할인·쿠폰·배송·구성 정보
- 상품 설명과 핵심 USP
- 원재료·성분·소재·제조 정보
- 실제 상품 이미지와 상세 이미지
- 확인 가능한 리뷰 인사이트
- 타깃 고객과 사용 상황 후보
- 광고 콘텐츠 참고사항
- 사용 가능한 수치와 금지 표현

분석 결과는 후킹을 만들기 위한 사실의 기준이다. 상품에 없는 효능, 숫자, 후기, 가격, 할인율, 수량, 중량, 평점, 판매량을 임의로 생성하지 않는다.

## 7. 후킹의 정의

후킹은 제목 한 줄이 아니라 하나의 **메시지 가설**이다.

```text
후킹 가설 = 메인 후킹 문구 + 후킹을 보완하는 서브 문구 1줄
```

- 메인 후킹은 첫 주목과 관심을 만든다.
- 서브 문구는 메인 후킹의 의미를 상품 사실과 연결한다.
- 가격·CTA·프로모션 정보는 공통 디자인 슬롯에서 동일하게 유지한다.
- 같은 후킹 안에서 서브 문구만 여러 개 만들어 별도 변수로 테스트하지 않는다.

후킹 가설에는 다음 정보를 저장한다.

- 후킹 ID: H01~H06
- 범용 후킹 분류
- 메인 후킹 문구
- 서브 문구 1줄
- 사용한 상품 사실 ID
- 추천 이유
- 기대하는 고객 반응
- 사용 금지 또는 검토가 필요한 표현

---

## 8. 범용 후킹 분류 체계

특정 육류나 화장품에 편중되지 않도록 패션·식품·농산물·화장품·생활용품 등에 공통 적용 가능한 분류를 사용한다.

| 후킹            | 코드 | 핵심 질문                         | 범용 적용 예시                          |
| --------------- | ---- | --------------------------------- | --------------------------------------- |
| 감각·경험형     | SEN  | 사용하면 무엇을 느끼는가?         | 맛, 향, 촉감, 착용감, 시원함, 편안함    |
| 문제 해결형     | PRB  | 어떤 불편을 해결하는가?           | 땀, 보관, 손질, 착용, 세척, 시간 부족   |
| 상황 공감형     | EMP  | 어떤 순간에 필요한가?             | 출근, 운동 후, 육아, 여행, 집들이, 명절 |
| 궁금증·정보형   | CUR  | 왜 더 알아보고 싶은가?            | 질문, 의외성, 확인된 숫자, 선택 기준    |
| 성분·소재·USP형 | USP  | 상품의 확인된 차이는 무엇인가?    | 원산지, 소재, 성분, 공법, 설계, 구성    |
| 타깃 지목형     | TGT  | 누구에게 특히 필요한가?           | 연령, 직업, 생활방식, 고민 상황         |
| 후기·신뢰형     | REV  | 실제 사용자가 무엇을 확인했는가?  | 반복 리뷰, 인증, 제조 정보, 사용 경험   |
| 가격·혜택형     | PRC  | 지금 선택할 구매 조건은 무엇인가? | 가격, 할인, 세트, 쿠폰, 배송 혜택       |

상품 사실이 부족한 분류는 억지로 채우지 않는다. 예를 들어 실제 후기 데이터가 없다면 REV 대신 브랜드 메시지형, 가치형, 신상품 탐색형 등 사실 기반 대체 후킹을 사용할 수 있다.

## 9. 후킹 예시

오리지널소스 민트 샤워젤의 예시는 다음과 같이 구성할 수 있다.

| ID  | 유형        | 메인 후킹 예시                            | 서브 문구 예시                                  |
| --- | ----------- | ----------------------------------------- | ----------------------------------------------- |
| H01 | 감각형      | 굿, 샤워만 했는데 북극 도착               | 민트의 상쾌한 사용감으로 마무리하는 여름 샤워   |
| H02 | 문제 해결형 | 아침에 샤워했는데 회사 도착하니 또 땀범벅 | 더운 날 반복되는 찝찝함을 산뜻한 샤워 루틴으로  |
| H03 | 상황형      | 운동 끝나고 바로 샤워해도 더운 사람 특징  | 운동 후 필요한 민트 샤워의 상쾌함               |
| H04 | 호기심형    | 샤워 후 체감온도 -8.9℃                    | 상품 근거에서 확인된 경우에만 수치를 사용       |
| H05 | 성분·USP형  | 민트잎 7,927장의 강력한 쿨링              | 실제 상세페이지 근거가 있을 때만 해당 표현 사용 |
| H06 | 타깃형      | 3040 남자들이 여름에 찾는 샤워젤          | 타깃 근거가 없다면 생활 상황 중심 문구로 대체   |

위 문장은 후킹 구조 예시다. 실제 생성 시에는 상세페이지·상품 데이터·리뷰에서 확인된 사실만 사용한다. 근거가 없는 `-8.9℃`, `7,927장`, 연령대 선호, 사용자 후기는 그대로 생성하지 않는다.

## 10. MVP 테스트 구조

### 10.1 전체 구조

```text
T00 기존 우승 소재 대조군 설정
→ T01 서로 다른 후킹 6개 생성
→ 하나의 고정 디자인 확정
→ 후킹 메시지가 다른 광고 이미지 6장 제작
→ 실제 광고 테스트
→ 후킹별 성과 비교
→ 우승 후킹 선정
→ 우승 후킹을 다음 콘텐츠 제작에 활용
```

T02·T03 실험 단계는 이 역사 문서의 MVP에서 사용하지 않는다. `상위 후킹 3개×이미지 6장`, `우승 후킹×이미지 6장` 구조도 당시 MVP 범위에서 제외했다. 별도 후킹 실험 화면의 후킹당 2개 표현은 Meta 등록 준비용 소재 변형이었다. 현재 기본 `/create-product` 흐름은 [광고 6장 생성 명세](creative-generation-spec.md)의 ZIP 레퍼런스 단계별 편집 방식을 따른다.

### 10.2 T00 기존 우승 소재 대조군

가능하면 동일 상품에서 실제로 사용하던 우승 소재 1~2장을 대조군으로 등록한다.

대조군에는 다음을 기록한다.

- 원본 소재코드 또는 신규 연결 코드
- 실제 사용 이미지
- 메인·서브 메시지
- 상품과 랜딩페이지
- 적용된 가격과 프로모션
- 캠페인 목표, 타깃, 게재 위치, 기간
- 과거 성과와 데이터 기준일

대조군은 신규 후킹의 상대 순위뿐 아니라 기존 제작 방식보다 실제로 나아졌는지를 판단하는 기준이다.

### 10.3 T01 후킹 실험

- 서로 다른 메시지 가설 6개를 만든다.
- 후킹마다 광고 이미지 1장만 만든다.
- 총 6장을 제작한다.
- 변경되는 것은 메인 후킹과 서브 문구 1줄뿐이다.
- 후킹 ID H01~H06을 소재코드와 연결한다.
- 충분한 데이터가 확보된 후 캠페인 목표의 핵심 지표로 순위를 정한다.

## 11. 실험에서 고정하는 요소

후킹 외 요소는 최대한 동일하게 유지한다.

| 구분           | 고정 조건                                |
| -------------- | ---------------------------------------- |
| 상품 이미지    | 동일한 원본 또는 동일한 승인 누끼 이미지 |
| 상품 크기·위치 | 같은 좌표와 비율                         |
| 배경           | 동일 이미지와 동일 크롭                  |
| 레이아웃       | 동일 슬롯과 정보 위계                    |
| 폰트·색상      | 동일 서체, 크기 정책, 컬러 토큰          |
| 가격·프로모션  | 동일한 확인값과 동일 표현                |
| CTA            | 동일 문구와 동일 위치                    |
| 랜딩페이지     | 동일 URL                                 |
| 캠페인 목표    | 하나의 실험 안에서 동일                  |
| 타깃           | 동일                                     |
| 게재 위치      | 동일                                     |
| 집행 기간      | 동일하거나 겹치는 비교 기간              |
| 예산·노출      | 후킹별 유사한 배분 조건                  |

고정된 디자인을 `ExperimentDesignSnapshot`으로 저장한다. 디자인 스냅샷에는 배경·레이아웃·상품 이미지·배치·폰트·색상·가격·CTA 설정을 보존하고, T01의 8개 소재가 같은 스냅샷을 참조하도록 한다.

### 변경 가능한 요소

- 메인 후킹 문구
- 후킹을 보완하는 서브 문구 1줄

텍스트 길이 차이 때문에 줄바꿈이 달라질 수 있으나 슬롯, 최대 줄 수, 폰트 축소 규칙은 동일하게 적용한다. 특정 후킹만 글자를 크게 하거나 장식을 추가하지 않는다.

## 12. 광고 테스트 운영 원칙

한 실험 안에서 다음 조건을 통일한다.

- 동일 캠페인 목표
- 동일 타깃과 제외 타깃
- 동일 게재 위치
- 동일 기여 설정
- 동일 랜딩페이지
- 동일 가격과 프로모션
- 동일 또는 겹치는 집행 기간
- 유사한 예산과 노출 기회

Meta의 자동 최적화로 특정 소재에 지출이 집중될 수 있으므로 후킹별 지출·노출 분포를 반드시 표시한다. 지출이 과도하게 집중되면 단순 순위를 확정하지 않고 비교 가능성 경고를 제공한다.

애드아틀란티스가 외부 서비스에 실제로 연결되지 않은 상태에서는 자동 등록·자동 집행·자동 수집이 가능한 것처럼 표현하지 않는다. MVP는 등록 패키지와 성과 보고서 업로드를 중심으로 운영한다.

---

## 13. 소재코드와 실험코드

### 13.1 후킹 중심 소재코드

```text
AT-{BRAND}-{ORIGINAL_PRODUCT_NO}-T{ROUND}-{HOOK_ID}
```

예시:

```text
AT-ORS-65-T01-H01
AT-ORS-65-T01-H02
AT-ORS-65-T01-H03
```

규칙:

- 동일한 실제 소재는 여러 목표에서 재사용해도 코드를 변경하지 않는다.
- 수정본은 원본 코드를 유지하고 `-V02`, `-V03`처럼 버전을 추가한다.
- 소재코드는 이미지 파일명, 권장 광고명, UTM `utm_content`, 내부 생성 기록, 성과 보고서에서 동일하게 사용한다.
- H01~H06과 후킹 유형 코드는 별도 필드로 함께 저장한다.
- 캠페인 목표는 소재코드에 넣지 않고 실험과 성과 레코드에 저장한다.

### 13.2 T00 대조군 코드

기존 소재코드가 있으면 그대로 연결한다. 코드가 없다면 다음처럼 관계 코드를 발급할 수 있다.

```text
AT-ORS-65-T00-C01
AT-ORS-65-T00-C02
```

### 13.3 실험코드

```text
EXP-{BRAND}-{ORIGINAL_PRODUCT_NO}-{OBJECTIVE}-T01
```

예시:

```text
EXP-ORS-65-SLS-T01
EXP-ORS-65-TRF-T01
```

목표가 다른 성과는 별도 실험으로 저장하여 서로 덮어쓰지 않는다.

## 14. 광고 등록 및 크리마 솔루션 연계

### 14.1 호스팅사 등록 패키지

후킹 실험별 ZIP에 다음을 포함한다.

```text
00_experiment/
  experiment-plan.xlsx
  experiment-guide.txt
  all-registration.xlsx
T00_control/
  control-registration.xlsx
  images/
T01_hooks/
  H01/
  H02/
  ...
  H08/
```

등록표에는 최소한 다음 정보가 포함된다.

- 실험코드
- 소재코드
- 후킹 ID와 후킹 유형
- 메인 후킹과 서브 문구
- 광고주·브랜드·원본 상품번호
- 상품명과 원본 상품 URL
- 이미지 파일명
- 권장 자체상품코드
- 권장 비노출 카테고리
- 권장 광고명
- 랜딩 URL과 UTM
- 호스팅사 등록 상품번호
- 크리마 애드 수집 상태
- 카탈로그 상품 ID와 매칭 상태
- 비고

### 14.2 크리마 연계 역할

크리마 솔루션 연계는 다음 두 역할로 구분한다.

1. 크리마켓: 광고 기회 상품 탐지와 상품·리뷰 데이터 보강
2. 크리마 애드: 후킹별 비노출 카테고리 또는 등록 상품의 수집·운영 상태 관리

실제 API·인증·등록 사양이 확인되지 않은 기능은 구현된 것처럼 표현하지 않는다. 연결이 없으면 ZIP·XLSX·CSV와 수동 상태 기록으로 운영한다.

## 15. 성과 보고서 연결

지원 입력은 Meta 보고서 CSV/XLSX를 기본으로 하며, 향후 Google 등 다른 매체를 같은 구조로 확장할 수 있다.

### 15.1 자동 연결

광고 이름에서 소재코드를 찾아 다음 관계를 연결한다.

```text
광고 보고서 행
→ 소재코드
→ ExperimentAsset
→ 후킹 ID와 메시지 가설
→ 상품·광고주·실험 목표
```

### 15.2 연결 상태

- 자동 연결 완료
- 코드 없음
- 소재를 찾지 못함
- 중복 코드 확인 필요
- 다른 실험 소재이므로 확인 필요
- 사용자 수동 연결 완료

`0`은 실제 성과 0으로 보존하고, 빈 값이나 미수집 값은 `null`로 저장한다.

---

## 16. 성과 계산 원칙

비율 지표를 행별로 평균내지 않는다. 먼저 원시 값을 합산한 후 비율을 계산한다.

```text
CTR = 전체 아웃바운드 클릭 ÷ 전체 노출
CPC = 전체 지출 ÷ 전체 아웃바운드 클릭
LPV 비용 = 전체 지출 ÷ 전체 랜딩페이지 조회
CVR = 전체 구매 ÷ 전체 랜딩페이지 조회 또는 사전 정의한 클릭 기준
CPA = 전체 지출 ÷ 전체 구매
ROAS = 전체 구매전환값 ÷ 전체 지출
참여율 = 전체 참여 ÷ 전체 노출
빈도 = 전체 노출 ÷ 전체 도달
```

CVR 분모는 실험 시작 전에 `랜딩페이지 조회` 또는 `아웃바운드 클릭` 중 하나로 확정하고 실험 도중 바꾸지 않는다.

---

## 17. 캠페인 목표별 성과 판단

### 17.1 인지도 캠페인

핵심 지표:

- 도달
- CPM
- 참여율
- 빈도

CTR은 주목도 확인을 위한 보조 지표로 사용한다.

### 17.2 유입 캠페인

핵심 지표:

- 아웃바운드 CTR
- CPC
- 랜딩페이지 조회당 비용

링크 클릭보다 아웃바운드 클릭과 실제 랜딩페이지 도달을 우선 확인한다.

### 17.3 판매 캠페인

핵심 지표:

- 구매
- CPA
- CVR
- ROAS

CTR은 후킹의 주목도를 보여주는 보조 지표다. 판매 캠페인의 최종 우승 후킹을 CTR만으로 결정하지 않는다.

## 18. 대조군 대비 개선율

T00과 T01의 조건이 비교 가능한 경우 다음 개선율을 표시한다.

```text
CTR 개선율 = (신규 CTR - 대조군 CTR) ÷ 대조군 CTR × 100
CPA 개선율 = (대조군 CPA - 신규 CPA) ÷ 대조군 CPA × 100
ROAS 개선율 = (신규 ROAS - 대조군 ROAS) ÷ 대조군 ROAS × 100
```

분모가 0이거나 미수집이면 개선율을 계산하지 않는다.

다음 조건이 다르면 개선율에 `참고 지표` 표시를 붙인다.

- 상품 또는 랜딩페이지
- 가격·프로모션
- 캠페인 목표
- 타깃
- 게재 위치
- 집행 기간
- 기여 설정
- 지출·노출 기회

조건이 충분히 유사할 때만 `기존 소재 대비 개선`으로 확정적으로 표현한다.

---

## 19. 데이터 충분도와 비교 가능성

실험 시작 전에 다음 기준을 설정하고 결과 화면에 함께 표시한다.

- 최소 노출
- 최소 아웃바운드 클릭
- 최소 랜딩페이지 조회
- 판매 캠페인의 최소 구매
- 후킹별 최대 허용 지출 불균형
- 단일 소재 최대 지출 집중도
- 허용 가능한 집행 기간 차이

다음 상황에서는 우승을 단정하지 않는다.

- 최소 집행 기준을 충족하지 못함
- 일부 후킹에만 지출이나 노출이 과도하게 집중됨
- 서로 다른 기간·목표·타깃이 섞임
- 판매 캠페인인데 구매 데이터가 부족함
- 소재코드가 연결되지 않은 보고서 행이 많음
- 대조군과 신규 소재의 상품·프로모션 조건이 다름

결과는 `추가 데이터 필요`로 표시하고, 부족한 조건과 필요한 다음 행동을 설명한다.

## 20. 후킹 성과 상태

각 후킹을 다음 네 상태로 분류한다.

| 상태        | 의미                                                                | 다음 행동                          |
| ----------- | ------------------------------------------------------------------- | ---------------------------------- |
| 검증된 우승 | 데이터가 충분하고 목표 핵심 지표에서 가장 우수하며 비교 조건도 충족 | 다음 콘텐츠의 메시지 방향으로 사용 |
| 유망 후킹   | 좋은 신호가 있으나 구매·노출·비교 조건이 충분하지 않음              | 추가 예산 또는 반복 검증           |
| 패배        | 데이터가 충분한 상태에서 핵심 지표가 기준과 경쟁 후킹보다 낮음      | 기본 추천에서 제외하되 기록은 유지 |
| 데이터 부족 | 최소 기준 또는 연결 품질을 충족하지 못함                            | 결과를 보류하고 데이터 추가        |

`검증된 우승`은 단순 1등과 다르다. 데이터 충분도, 비교 가능성, 캠페인 목표의 핵심 지표, 지출 집중도, 대조군 대비 성과를 함께 확인해야 한다.

---

## 21. CTR·CVR 조합 진단

CTR과 CVR의 조합은 원인 확정이 아니라 **가능성이 높은 진단**으로만 표시한다.

| 관찰값            | 가능한 진단                                             | 확정할 수 없는 이유                         |
| ----------------- | ------------------------------------------------------- | ------------------------------------------- |
| CTR 높음·CVR 높음 | 후킹과 랜딩의 메시지 연결이 좋을 가능성                 | 가격, 타깃, 매체 최적화 영향이 있을 수 있음 |
| CTR 높음·CVR 낮음 | 호기심은 만들었지만 랜딩·혜택 기대가 맞지 않을 가능성   | 구매 주기나 재고, 결제 경험 영향 가능       |
| CTR 낮음·CVR 높음 | 주목도는 약하지만 반응한 고객의 구매 의도가 높을 가능성 | 작은 표본 또는 특정 타깃 집중 가능          |
| CTR 낮음·CVR 낮음 | 메시지와 고객 문제의 적합도가 낮을 가능성               | 노출 품질이나 집행 조건 문제 가능           |

UI에서는 `원인` 대신 `가능한 해석`, `추가 확인 항목`이라는 표현을 사용한다.

## 22. 결과 화면

실험 결과에는 다음 정보를 제공한다.

- 가장 높은 성과를 기록한 후킹
- 후킹별 메인·서브 메시지
- 기존 소재 대비 개선율 또는 참고 개선율
- 후킹별 성과 순위
- 캠페인 목표별 핵심 지표
- CTR 등 보조 지표
- 데이터 충분도
- 후킹별 지출·노출 분포
- 검증된 우승·유망·패배·데이터 부족 상태
- 우승 후킹으로 판단한 이유
- 가능한 성과 진단과 추가 확인 항목
- 다음 콘텐츠에서 유지할 메시지
- 다른 상품에서도 추가 검증할 범용 후킹 유형

결과가 충분하지 않으면 우승 카드 대신 `추가 데이터 필요` 카드와 부족한 기준을 우선 표시한다.

---

## 23. 우승 후킹의 다음 행동

결과 화면에 다음 행동을 제공한다.

```text
[우승 후킹으로 다음 콘텐츠 만들기]
```

버튼을 누르면 다음 정보가 기존 콘텐츠 제작 화면으로 전달된다.

- 상품과 상품 이미지
- 우승 후킹 유형
- 메인 후킹과 서브 문구
- 사용한 상품 사실
- 우승으로 판단한 목표와 근거
- 유지해야 할 메시지 방향
- 금지 표현과 콘텐츠 참고사항

다음 콘텐츠에서는 우승한 메시지 방향을 유지할 수 있다. 다만 새로운 배경·레이아웃을 사용하더라도 그것이 더 높은 성과를 낼 것이라고 자동 판단하거나, MVP가 비주얼 효과까지 학습했다고 표현하지 않는다.

---

## 24. 목표별 학습

후킹 성과는 실제 테스트 목표와 함께 저장한다. 콘텐츠 생성 단계에서 감각형은 인지도용, 가격형은 판매용처럼 미리 제한하지 않는다.

동일한 후킹이 여러 목표에서 테스트될 수 있으며 성과는 별도 레코드로 보존한다.

목표별 추천은 다음 원칙을 따른다.

- 한 번의 우승만으로 범용 추천을 확정하지 않는다.
- 적격 실험 수와 적격 소재 수를 함께 확인한다.
- 초기 신호와 반복 신호를 검증 완료와 구분한다.
- 광고주·상품·카테고리 간 일반화는 MVP에서 보수적으로 수행한다.
- 상품이 다른 실험은 동일 상품 실험보다 낮은 증거 수준으로 취급한다.

MVP의 핵심 학습 단위는 `상품 × 캠페인 목표 × 후킹 메시지 가설`이다.

- 크리마 애드 수집 및 상품 매칭 상태 기록

- 비주얼 요소별 성과 기여도 계산
- 소재 피로 자동 판정
- 외부 서비스 사양이 없는 자동 등록·자동 집행

## 28. 향후 고도화 방향

아래 기능은 삭제하지 않고 후속 단계로 관리한다.

1. 우승 후킹별 이미지 6장 제작
2. 동일 후킹 내 배경과 레이아웃 테스트
3. 상품 크기와 배치 테스트
4. 카피 길이 테스트
5. 가격 우선과 효능 우선 비교
6. 후킹 효과와 비주얼 효과 분리
7. 소재 피로 감지
8. 우승 후킹을 활용한 새로운 비주얼 자동 생성
9. 광고주·상품·카테고리별 장기 성과 학습

고도화 단계에서도 한 번에 너무 많은 변수를 변경하지 않는다. 후킹을 검증한 뒤 비주얼 변수를 하나씩 추가하는 순차 실험 구조를 사용한다.

## 29. 사업성

### 29.1 핵심 고객

- 다수 이커머스 광고주를 운영하는 광고대행사
- 크리마 리뷰·크리마켓 데이터를 사용하는 쇼핑몰
- 사내 퍼포먼스 마케팅팀과 콘텐츠 제작팀
- 반복적인 광고 소재 제작과 성과 정리가 필요한 브랜드

### 29.2 고객 가치

- 상품 선정부터 광고 테스트까지 한 흐름으로 연결
- 감에 의존하던 후킹 제작을 실제 성과 데이터로 전환
- 기존 우승 소재 대비 개선 여부를 명확하게 확인
- 이미지 파일과 광고 보고서의 수작업 매칭 감소
- 검증된 메시지를 다음 콘텐츠 제작에 재사용
- 크리마 데이터가 없는 광고주도 상세페이지 방식으로 사용 가능

### 29.3 제품 차별점

애드아틀란티스의 차별점은 단순 이미지 생성량이 아니다.

```text
광고 기회 상품 발견
+ 상품 사실 기반 후킹 가설 생성
+ 통제된 동일 디자인 실험
+ 소재코드 기반 성과 연결
+ 우승 메시지의 다음 제작 재사용
```

### 29.4 사업 검증 지표

- 후킹 실험을 시작한 광고주 수
- 생성한 실험 중 실제 보고서가 연결된 비율
- 소재 자동 매칭률
- 데이터 충분도를 충족한 실험 비율
- 기존 소재 대비 핵심 지표 개선 실험 비율
- 우승 후킹으로 다음 콘텐츠를 만든 비율
- 실험 준비와 성과 정리에 절감된 운영 시간
- 크리마켓 추천 상품에서 실제 실험으로 전환된 비율

## 30. 기대 효과

### 광고 운영자

- 어떤 후킹이 실제 성과를 만들었는지 빠르게 확인한다.
- 데이터가 부족한 결과를 우승으로 오판하지 않는다.
- 기존 소재 대비 개선을 같은 조건에서 확인한다.

### 콘텐츠 제작자

- 상품 사실과 검증된 메시지 방향을 전달받는다.
- 다음 제작에서 유지할 문구와 피할 문구가 명확해진다.
- 디자인 취향이 아니라 메시지 가설 단위로 피드백을 받는다.

### 광고주와 브랜드

- 상품·고객·목표별로 반응하는 메시지 자산이 축적된다.
- 크리마켓 데이터와 광고 실행 결과가 하나의 흐름으로 연결된다.
- 크리마 미연결 상태에서도 같은 실험 체계를 사용할 수 있다.

---

## 31. 성공 기준

MVP는 다음 조건을 만족할 때 성공으로 본다.

- 하나의 상품에서 사실 기반 후킹 가설 8개를 만들 수 있다.
- 메인 후킹과 서브 문구 외 디자인 요소가 동일하게 렌더링된다.
- T00 대조군 1~2장을 선택적으로 연결할 수 있다.
- 8개 이미지의 파일명·광고명·UTM에 동일 소재코드가 사용된다.
- 등록 패키지로 실제 수동 등록 업무를 수행할 수 있다.
- Meta 보고서의 광고명이 실험 소재와 자동 연결된다.
- 목표별 핵심 지표가 원시 합계 기준으로 계산된다.
- 기존 소재 대비 개선율과 비교 가능 여부가 함께 표시된다.
- 데이터가 부족하면 우승을 만들지 않는다.
- 결과가 네 가지 성과 상태로 구분된다.
- 우승 후킹의 메시지가 다음 콘텐츠 제작으로 전달된다.
- 어디에서도 비주얼 효과까지 검증했다고 과장하지 않는다.

---

## 32. 최종 제품 메시지

### 한 줄 소개

> 동일한 광고 디자인에 서로 다른 후킹을 적용해 실제 광고 성과를 비교하고, 고객이 반응하는 메시지를 학습하는 AI 광고 콘텐츠 실험 시스템입니다.

### 보조 소개

> 광고할 상품을 찾고, 상품 사실에 근거한 후킹 6개를 테스트하며, 실제 성과를 다음 콘텐츠 제작에 연결합니다.

### 표현하지 않는 문구

- AI가 후킹과 디자인의 성과 기여도를 자동 분리합니다.
- 배경·레이아웃·상품 배치를 자동으로 최적화합니다.
- 한 번의 테스트로 모든 상품에 통하는 우승 공식을 찾습니다.
- 광고를 자동 등록하고 성과를 실시간 수집합니다. — 실제 연동이 없는 경우
- 데이터가 적어도 우승 소재를 정확하게 판정합니다.

현재 MVP가 제공하는 것은 **통제된 후킹 비교, 정확한 성과 연결, 보수적인 우승 판정, 검증 메시지의 다음 제작 활용**이다.
