# CategoryProfile 운영 가이드

카테고리 프로필은 브랜드가 매칭되지 않아도 타깃·색·장면·구도를 합리적으로 선택하기 위한 fallback이다. 정의 원본은 `data/category-profiles.json`이다.

## personal-care

실사용 문제 상황, 샤워/운동 후 장면, 깨끗한 제품 stage를 우선한다. 실제 패키지 라벨을 보존하고 체취 감소율·체감 온도·의학적 효능을 추정하지 않는다.

## food-meat

실제 판매 부위와 포장 상태를 유지한다. 그릴·식탁·선물 장면은 보조 배경이며 등급, 중량, 원산지, 가격은 ProductTruth에 있을 때만 표시한다.

## agriculture

실제 품종과 색, 판매 구성, 일반화된 산지 분위기를 우선한다. 특정 산지, 당도, 유기농·무농약 인증을 추정하지 않는다.

## fashion

착용 실루엣, 스타일링 상황, 색·핏 보존을 우선한다. 모델이 포함된 상품 이미지를 다시 생성하거나 체형 보정을 주장하지 않는다. 리리앤코는 이 카테고리의 브랜드 프로필 예시다.

## generic-commerce

제품 식별, 한 가지 핵심 혜택, 명확한 CTA를 우선한다. 제품 히어로형을 첫 fallback으로 사용하고 브랜드 색이 없으면 파랑/네이비/흰색/노랑의 고대비 팔레트를 사용한다.

## BrandProfile 예시

- 오리지널소스: 민트·청록·검정, 문제 해결/감각/쿨링 장면, exact wordmark.
- 국대한우: 적색·노랑·검정, 그릴/식탁/가격·품질 위계, exact symbol.
- 힘내라농가: 녹색·황색·크림, 산지/수확/정직한 구성, 로고 없음 fallback.
- 리리앤코: 뉴트럴 브라운·크림, 룩북/에디토리얼/채팅 UGC, exact logo와 `ririnco.com` 도메인 매칭.

브랜드별 분기는 코드 `if` 문이 아니라 `data/advertisers/*.json`과 프로필 adapter에서 처리한다.
