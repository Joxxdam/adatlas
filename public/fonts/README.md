# AdAtlas bundled fonts

광고 렌더링 결과가 운영체제에 따라 달라지지 않도록 아래 Google Fonts 원본 TTF를 프로젝트에 포함합니다.

| ---------------------------- | ---------------- | --------------------------------- | ------------------------------------------------------------ | --------------------------------- |
| `BlackHanSans-Regular.ttf`   | Black Han Sans   | 강한 특가·가격·식품 헤드라인      | https://github.com/google/fonts/tree/main/ofl/blackhansans   | `licenses/BlackHanSans-OFL.txt`   |
| `DoHyeon-Regular.ttf`        | Do Hyeon         | 설명·비교·근거형 헤드라인         | https://github.com/google/fonts/tree/main/ofl/dohyeon        | `licenses/DoHyeon-OFL.txt`        |
| `GowunBatang-Bold.ttf`       | Gowun Batang     | 프리미엄·선물·에디토리얼 헤드라인 | https://github.com/google/fonts/tree/main/ofl/gowunbatang    | `licenses/GowunBatang-OFL.txt`    |
| `NanumPenScript-Regular.ttf` | Nanum Pen Script | 후기·UGC·손글씨형 헤드라인        | https://github.com/google/fonts/tree/main/ofl/nanumpenscript | `licenses/NanumPenScript-OFL.txt` |
| `NotoSansKR-Variable.ttf`    | Noto Sans KR     | 모든 템플릿의 본문·가격·CTA       | https://github.com/google/fonts/tree/main/ofl/notosanskr     | `licenses/NotoSansKR-OFL.txt`     |

모든 파일은 각 폰트 디렉터리에 포함된 SIL Open Font License 1.1 조건으로 재배포합니다. 폰트 파일 자체를 단독 판매하지 않고, 수정본을 배포할 때는 각 라이선스의 Reserved Font Name 조건을 확인해야 합니다.
