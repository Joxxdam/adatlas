# 힘내라농가 광고 카피 가이드

## 브랜드 핵심 톤

- 산지직송, 농민/산지 물량, 유통 단계 축소, 단가 착시를 가격을 납득시키는 근거로 사용한다.
- `힘농`, `힘농 식구님`은 커뮤니티와 단골 추천 맥락에서만 자연스럽게 사용한다.
- 국대한우의 개인 정육점 서사나 대한한우의 왕도매가 세계관을 섞지 않는다.
- 실제 상품 정보에 없는 수량, 할인율, 원산지, 생산 방식, 환불 조건, 재구매율은 만들지 않는다.
- 이모지와 그림문자는 절대 출력하지 않는다. 별표, 물음표, 느낌표도 꼭 필요한 경우에만 제한적으로 쓴다.

## 1. 헤드라인: 최저가와 산지 특가

- 구조: `[가격 반전] + [산지/품종/상품] + [한정 또는 특가 명분]`
- 활용 어휘: 전국최저가 도전, 가격파괴, 초특가 한정판매, 선착순 특가, 감사특가, 역대급 특가
- 예시 방향: `이 가격이 맞나 싶은 산지 특가`, `이번 물량만, 산지직송 특가`, `가격표 다시 보게 되는 구성`

## 2. 한정 수량과 긴급성

- 수량, 기간, 예약발송은 상세페이지에 확인되는 경우에만 쓴다.
- 확인되지 않은 숫자는 만들지 말고 `이번 물량`, `준비 수량`, `시즌 한정`처럼 사실을 과장하지 않는 표현으로 바꾼다.

## 3. 개당/마리당/팩당 단가 프레이밍

- 실제 가격과 수량/중량으로 검증할 수 있을 때만 `개당`, `마리당`, `1팩`, `kg당`, `1인분` 단가를 계산해 사용한다.
- 계산할 근거가 없으면 단가를 추정하지 않고, 구성과 가격의 납득감을 설명한다.
- 예시 방향: `이 구성이라 더 놀라운 산지 특가`, `유통 단계를 줄여 부담을 낮춘 가격`

## 4. 산지와 품질 신뢰

- bodyCopy 중심: 산지직송, 당일손질, 국내산, 선별, 장인, 품종, 제철, 신선도
- 원산지, 손질 방식, 품종, 인증 등은 productInfo에 있는 사실만 사용한다.
- 예시 방향: `산지에서 바로 보내 신선함을 살린 제철 구성입니다.`

## 5. 반전/의심형 후킹

- 헤드라인에서만 `가격표를 다시 보게 되는`, `이 정도면 반칙 아닌가요`, `속는 셈 치고 담아볼 구성` 같은 가벼운 반전을 사용한다.
- 환불, 사기, 낙찰 오류, 손해 판매 등 사실 확인이 어려운 단정적 표현은 쓰지 않는다.

## 6. 커뮤니티와 재구매 프레이밍

- `힘농 식구님들이 고른`, `단골 추천`, `리얼 후기`는 실제 후기/판매 근거가 있을 때만 사용한다.
- 근거가 없으면 `다시 찾게 되는 구성`, `단골 장바구니에 담기 좋은 구성`처럼 보수적으로 표현한다.

## 슬롯별 작성 규칙

- headline: 가격 반전 또는 산지 특가로 짧고 강하게 시작한다.
- bodyCopy: 산지, 품질, 제철, 구성, 활용도를 존댓말 한 문장으로 설명한다.
- highlightCopy: `산지직송`, `이번 물량`, `한정 특가`, `유통 단계 축소`처럼 짧게 쓴다.
- bottomBarCopy: 가격의 근거나 구매 명분을 간결하게 보조한다.
- cta: `산지 특가 보기`, `구성 확인하기`, `지금 담기`처럼 행동만 명확히 쓴다.

## 브랜드 구분

- 대한한우의 왕도매가, 王 표기, 궁중 납품 세계관을 핵심 후킹으로 사용하지 않는다.
- 국대한우의 사장님/정육점 개인 고백 말투를 그대로 사용하지 않는다.
